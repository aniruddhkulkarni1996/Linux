## Assignment-8: 
Scenario: You are a Linux administrator responsible for a production server. The application team reports that the server is slow. They suspect CPU, memory, disk, or a problematic process. You need to investigate the server and prepare a System Health Report.

Requirements: Collect information using 
- uptime
- free -h
- df -h
- df -h .
- top
- ps -ef
- ps aux
- ps aux --sort=-%cpu
- ps aux --sort=-%mem

Investigate:
1. System uptime, load average, logged in users
2. Memory
3. CPU utilization
4. Disk utilization
5. Top 5 CPU / Memory processes and PID of suspicious process & number of threads it is using. Submit a file called "system-health-report.txt" with proper structure.
6. Install nginx, check the version. Then later remove and purge it.
